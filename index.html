AiBox / 使用说明

AiBox.
先把顺序搞清楚。

这不是一份促销页。下面按时间顺序把事情排开：先确认自己的用量，再挑档位，最后按平台把客户端装好。每一步都有明确的下一步。

  1. 01

    先算清一个月的用量

    把日常设备都列出来：手机、笔记本、平板，再加上可能同时在线的那一两台。设备数往往比流量更早触到上限，先数设备，再估流量。

  2. 02

    对照档位，选出够用的那一档

    三档的差别集中在三处：每月流量、同时在线设备数、可用线路范围。如果某一档刚好卡在你日常用量的边缘，往上选一档通常比中途换档省事。

  3. 03

    确认是月付还是年付

    年付把十二个月一次性结清，单月成本更低，但周期内不拆分。第一次使用建议先按月付走完一个完整周期，再决定要不要改年付。

  4. 04

    按设备平台装客户端

    不同系统的安装方式不一样。桌面端和移动端分开处理，装完之后先用一台设备跑通，再往其余设备上铺开。

  5. 05

    把用量和设备数记在同一个地方

    每月固定看一次流量剩余和在线设备列表。发现某一项长期贴着上限，就是下次调整档位的依据，而不是等到被限制时才处理。

开始之前，先过一遍这份清单

下面三项如果都能给出确定答案，选档位基本不会出错。任何一项答不上来，就先停在原地把答案补齐。

清单 A

设备清单

家里与随身携带的设备分开记，标注哪些会同时在线。

  • 手机会全天在线吗
  • 笔记本是否与手机同时用
  • 平板与电视盒子是否计入
  • 有没有临时加入的设备
清单 B

流量习惯

按“轻度 / 中度 / 重度”给自己一个区间，不必精确到 GB。

  • 以文字与网页为主
  • 经常看视频或下载
  • 有固定的大文件传输
  • 用量是否随季节波动
清单 C

结算方式

先想清楚周期，再决定付几个月。周期内不拆分。

  • 先按月付观察一个月
  • 或直接年付锁定成本
  • 团队用需先定人数
  • 记录续费到期日

客户端：按平台分开处理

桌面端与移动端的安装路径不同，先在一台设备上跑通，再把配置带到其余设备。下载入口以你实际获得的安装包为准，本页不提供下载地址。

桌面端 · Windows

安装后先登录账户，再在设备列表里确认这台机器已被计入在线数。首次配置建议只保留一组线路，跑通后再增加。

状态：安装包与更新入口见账户内说明

桌面端 · macOS

安装时按系统提示完成授权，随后在同一账户下核对设备名额。若与其他设备共用账户，注意同时在线台数的上限。

状态：安装包与更新入口见账户内说明

移动端 · iOS

通过 App Store 获取对应客户端，登录后与桌面端共用同一份设备名额。切换网络后建议重新确认线路状态。

状态：以 App Store 内实际可获取的版本为准

移动端 · Android

安装包由账户内页面提供，安装前请确认来源。装好后先做一次连接确认，再决定是否让其常驻后台。

几条使用上的硬规则

这些不是建议，是会影响你能否正常使用的前提。

规则 1

设备名额按“同时在线”算

登出不会自动释放名额，只有在设备列表中移除该设备，才把位置让出来。换新机前先移除旧机。

规则 2

流量按自然月重置

当月未用完的部分不结转到下月。月底前若剩余较多，说明档位选高了，可作为下次调整的依据。

规则 3

一个账户对应一个人或一个团队

团队版按人数与设备数规划，先定人再定档。账户共享给名单之外的人，不在服务范围内。

常见问题

按提问频率排列，答案尽量给到可以直接执行的程度。

Q1不确定自己该选哪一档，怎么判断？

先数同时在线的设备，再想一个月的流量习惯。设备数先到上限就按设备选，流量先到上限就按流量选。两项都卡在边缘时，往上选一档。

Q2年付和月付的差别只有价格吗？

年付是把十二个月一次性结清，单月成本更低，但周期内不拆分、不支持中途换档。第一次使用建议先按月付走完一个完整周期。

Q3三档之间的核心差别是什么？

三处：每月流量（100GB / 300GB / 1000GB）、同时在线设备（3 / 5 / 20 台）、线路范围。团队版另外支持企业定制路由与专属客户经理。

Q4换设备后名额没有释放怎么办？

登出不会自动腾出位置。需要在设备列表里手动移除不再使用的设备，名额才会回到可用状态。换新机之前，先移除旧机。

Q5客户端从哪里获取？

本页不提供下载地址。桌面端与移动端的安装包以你账户内页面所列的入口为准，iOS 端以 App Store 内实际可获取的版本为准。

Q6当月流量没用完，会留到下个月吗？

不会。流量按自然月重置，未用完的部分不结转。连续几个月都有明显剩余，说明当前档位对你偏高。

Q7团队版适合什么规模的使用？

团队版提供 1000GB 流量、20 台同时在线设备、VIP 专属高带宽节点、企业定制路由与专属客户经理。建议先确定人数与设备总数，再决定是否选它。

Q8页面上没有写到的能力，算不算包含？

不算。本页只列出已明确写出的价格与权益，未列出的项目不在承诺范围内。遇到页面上没有的内容，按账户内实际说明为准。
